## 1. 개요
- **한 줄 정의:** 주식 투자를 처음 시작하는 초보자를 위해, 투자 목표·리스크 성향과 재무·시장 데이터를 결합해 종목과 포트폴리오 구성을 추천해 주는 모바일 앱
- **해결하는 문제:** 투자 초보자는 어떤 종목을 사야 할지 판단할 기준(재무 지표 해석, 리스크 관리)이 없어 막연하게 투자를 시작하거나 시작을 미룬다
- **타깃 사용자:** 주식 투자를 처음 시작하는 초보자
- **플랫폼:** 모바일 앱 (iOS + Android)

## 2. 배경 & 근거
- **시장/경쟁 맥락:** ⚠️ (benchmark.md 없음 — 추후 보완. benchmark-research 스킬로 증권사 자체 추천 서비스, 로보어드바이저, 투자 정보 앱과의 비교가 필요하다.)
- **우리의 차별 프레이밍:** ⚠️ (benchmark.md 없음 — 추후 보완. 현재는 "리스크 성향·목표 입력 + 재무·시장 데이터 분석 기반 추천, 이후 전문가 큐레이션 반영"이라는 인터뷰상의 방향성만 있고, 구체적 차별점은 검증되지 않음.)

> ⚠️ **규제 관련 중요 고지:** 특정 종목을 추천하는 서비스는 국가별로 투자자문업 등 금융 규제 대상이 될 수 있다. 자세한 내용은 12번 오픈 이슈를 반드시 확인할 것.

## 3. 목표 (Goals)
- 투자 초보자가 재무 지식이 없어도 자신의 목표·리스크 성향에 맞는 종목과 포트폴리오를 추천받게 한다.
- 모든 추천에 이해 가능한 근거와 위험 고지를 함께 제공해 신뢰할 수 있는 판단을 돕는다.
- 목표·리스크 입력부터 추천 확인까지의 과정을 짧게 만들어 이탈을 최소화한다.

## 4. User Scenarios   ← 사용자 인터뷰
### Scenario 1 — 초보 투자자의 첫 포트폴리오 추천 받기
- **사용자:** 주식 투자를 처음 시작하는 초보자
- **상황:** 투자를 하고 싶지만 어떤 종목을 사야 할지 모름
- **목표:** 내 목표와 리스크 성향에 맞는 종목과 포트폴리오를 추천받고 싶음
- **흐름:** 앱 실행 → 투자 목표·리스크 성향·투자 가능 금액/기간 입력 → 추천 종목 및 포트폴리오 구성 확인
- **완료 조건:** 사용자가 자신에게 맞춰진 추천 종목 목록과 비중이 표시된 포트폴리오를 확인한다

### Scenario 2 — 추천 종목의 이유 확인하기
- **사용자:** 추천을 받은 초보자
- **상황:** 왜 이 종목이 추천됐는지 이해하고 싶음
- **목표:** 추천 근거를 확인해 신뢰하고 판단하고 싶음
- **흐름:** 추천 목록에서 종목 선택 → 상세 화면에서 핵심 지표·추천 사유 확인
- **완료 조건:** 사용자가 해당 종목의 추천 사유와 투자 위험 고지 문구를 함께 확인한다

### Scenario 3 — 리스크 성향 바꿔 재추천 받기
- **사용자:** 기존 이용자
- **상황:** 처음 설정한 리스크 성향이나 투자 목표가 바뀜
- **목표:** 변경된 조건으로 다시 추천받고 싶음
- **흐름:** 설정 화면에서 목표/리스크 성향 수정 → 재계산 → 새 포트폴리오 확인
- **완료 조건:** 수정된 조건이 반영된 새 포트폴리오가 표시된다

## 6. Success Criteria
- SC-001: 신규 사용자가 목표·리스크 성향·투자 금액 입력을 마치고 추천 포트폴리오를 확인하기까지 3분 이내에 완료한다. (⚠️ 가설 — 실측 검증 필요, 오픈 이슈 참조)
- SC-002: 추천 종목·포트폴리오 화면에 투자 위험 고지 문구가 표시되는 비율이 100%다.
- SC-003: 제시된 포트폴리오의 종목별 비중 합이 항상 100%로 일치한다.

## 7. Edge Cases
- 사용자가 리스크 성향 설문에 응답하지 않고 추천을 요청하는 경우: 최소 필수 입력을 안내하고 진행을 막는다.
- 투자 가능 금액이 추천 포트폴리오 구성에 필요한 최소 매매 단위보다 적은 경우: 대안(소수점 매매 안내 등)을 제시하거나 한계를 안내한다.
- 시장 데이터가 최신화되지 않았거나 제공사 오류인 경우: 데이터 최신성을 안내하거나 오류 상태를 표시한다.
- 리스크 성향(보수적)과 투자 목표(단기 고수익)가 서로 모순되는 경우: 안전 성향(리스크 제약)을 우선 반영하고, 모순 사실을 사용자에게 안내해 재확인을 요청한다.
- 추천 종목이 상장폐지·거래정지된 경우: 해당 종목을 추천에서 자동 제외하고 대체 종목을 제시한다.
- 네트워크/데이터 제공사 오류로 추천을 받지 못하는 경우: 오류 상태와 재시도 옵션을 제공한다.

## 10. 범위 / 비범위 & 우선순위
- **v1 범위:** 투자 목표·리스크 성향·금액/기간 입력(FR-001~003), 데이터 기반 종목 추천(FR-004), 종목 정보 확인(FR-005), 포트폴리오 구성 제시(FR-006~007), 위험 고지 표시(FR-008)
- **Out of scope (지금 안 함):** 실제 매매 연동(FR-012), 전문가 큐레이션 반영(FR-011)은 v1 이후. 포트폴리오 조정(FR-010)·재계산(FR-009)은 v1 범위에 포함하되 첫 출시 우선순위는 아님
- **우선순위 묶음(제품 관점):** MVP = FR-001~FR-008 (프로필 입력 → 데이터 기반 추천 → 포트폴리오 제시 → 위험 고지) / v1 = MVP + FR-009, FR-010, FR-011 (재계산, 비중 조정, 전문가 큐레이션 반영) / 이후 = FR-012 및 매매 연동 확장
- *구현 마일스톤 로드맵은 vibe-build의 roadmap 스킬이 docs/stock/ROADMAP.md에 작성한다.*

## 11. Assumptions
- 재무·시장 데이터(재무제표, 밸류에이션 지표, 시세 등)는 외부 데이터 제공자(증권사 API, 금융 데이터 벤더 등)로부터 가져온다고 가정한다. 구체적 소스는 미정.
- v1의 추천 로직은 규칙/스코어링 기반 매칭(리스크 성향 × 재무지표)으로 시작하며, 전문가·애널리스트 큐레이션 반영(FR-011)은 v1 다음 단계로 가정한다.
- 실제 매매는 v1에서 앱 내부에서 이뤄지지 않고, 필요 시 외부 증권사로 연결하는 것으로 가정한다(v1 이후, FR-012).
- 본 서비스의 추천은 확정적 매수 지시가 아니라 참고 정보로 제공되는 것을 전제로 한다고 가정한다 — 법적 성격 확정은 별도 검토 필요(12번 참조).
- 서비스 이름과 브랜드 톤은 아직 확정되지 않았으며, 별도 brand-voice·design-brandfit 단계에서 정해진다고 가정한다.

## 12. 오픈 이슈 / 리스크
- **⚠️ 규제/라이선스 검토 필요 (최우선):** 특정 종목을 추천하는 서비스는 국가별로 투자자문업·유사투자자문업 등 금융 규제 대상이 될 수 있다(예: 한국 자본시장법상 투자자문업 인가/등록, 미국의 투자자문업자 규제 등). 개발 착수 전 법무 검토와 필요한 인허가 확보 여부를 반드시 확인해야 한다. 이 PRD는 그 결과에 따라 서비스 형태(참고 정보 제공 vs 정식 투자자문)가 달라질 수 있다.
- 경쟁 서비스(증권사 앱, 로보어드바이저 등) 대비 차별화 포인트가 검증되지 않음 — benchmark-research 필요.
- 재무·시장 데이터 제공처(API 계약, 실시간성, 비용)가 정해지지 않음.
- 전문가·애널리스트 큐레이션을 어떤 방식(자체 인력 채용 vs 외부 제휴)으로 반영할지 미정.
- 추천 알고리즘의 구체적 스코어링/매칭 로직이 정의되지 않음 — 별도 설계 필요.
- 입력~추천 확인 "3분 이내"(SC-001) 목표는 실측 없는 가설이다.
- 상세 화면/온보딩 플로우(userflow) 미설계.
- 서비스 이름·브랜드 보이스·시각 디자인 시스템 전부 미정.
